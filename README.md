# Sydney trip

A six-day plan, Saturday 7 November to Thursday 12 November 2026, made from the reels. Each place says what you do there and links to the reel. There is no paste box.

## Run it on your computer

Open `index.html` in a browser, or from this folder:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Publish it on GitHub

You need a GitHub account and Git installed. The repository should be **public**. GitHub’s free plan serves Pages from a public repository. A private repository needs a paid GitHub plan before Pages will serve it.

The published page is the six-day plan. It is already at `https://tokieggg.github.io/reeltrip/`.

### Put it on your phone

Open that link in Safari or Chrome. Use **Share**, then **Add to Home Screen**.

Send the same link to the other person.
